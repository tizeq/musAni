# musAni v0.1.0-alpha.1 — First Public Alpha

This is the first public alpha of musAni, an offline music player for Linux x86-64.

## What's included

- A local music library with search, sorting, cover art, and tabs for artists and albums.
- Playback from the selected track in a list or playlist, with a queue, shuffle,
  and track or queue repeat.
- Playlists with custom artwork and track ordering. A playlist can also appear as an album.
- MP3 and FLAC tag editing with support for multiple artists and automatic backups.
- The Minimal and Atmosphere themes, reduced motion, and configurable shortcuts.

## Download

Download `musAni-v0.1.0-alpha.1-linux-x86_64.tar.gz` and its `.sha256` file.
Verify the checksum, extract the entire archive, and run `./musani` from the
extracted directory. The build uses system GTK 3, libmpv, SQLite, and libcurl.
See the [README for install commands and requirements](https://github.com/tizeq/musAni/blob/v0.1.0-alpha.1/README.md).

The separate `-source.tar.gz` asset contains the matching sources, license
notices, and TagLib relinking materials. It also has its own checksum file.

## Alpha limitations

This build requires x86-64 Linux with glibc and a graphical session. The
interface uses Russian. The current queue is session-only, library refreshes
are manual, and streaming and synchronization are unavailable. Playback
codec support depends on your system's libmpv.

If you find an issue, [report it on GitHub](https://github.com/tizeq/musAni/issues)
with your distribution, display session, and steps to reproduce.
