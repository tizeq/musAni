# Some Optimization and Album Improvements

This update improves performance, responsiveness, and album management.

### Performance

- Up to 3.2x faster library rescanning in a benchmark with 12,000 tracks.
- Significantly faster artist filtering.
- Optimized SQLite queries and metadata loading.
- Improved artwork caching.
- Reduced unnecessary UI rebuilds.
- Smoother scrolling and navigation.
- Improved Atmosphere theme performance.

### Album improvements

- Playlists can now function as proper albums.
- Shared album artwork and metadata.
- Automatic metadata inheritance for album tracks.
- Automatic track numbering.
- Multi-disc album support.
- Batch metadata editing for MP3 and FLAC.
- Improved album integration across the library, search, playback queue, and player.
- Safe metadata writing with backups.

### Known issues

- Occasional frame drops may still occur in the Atmosphere theme.
