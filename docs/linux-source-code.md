# Исходники и перелинковка Linux bundle

Для этой сборки вместе с бинарным архивом предоставляется
`musAni-v0.1.0-alpha.1-linux-x86_64-source.tar.gz`. В нём находятся исходники
musAni, зафиксированные исходники зависимостей, исходники TagLib 2.3 и моста,
объект моста и команды сборки. Файл `SOURCE-TREE` связывает комплект
с деревом Git бинарной сборки. При публикации комплект исходников доступен
рядом с бинарным архивом без дополнительной платы.

TagLib статически включена в `libflutter_taglib_native.so` по LGPL 2.1.
Приложение загружает мост как отдельную библиотеку. Для замены TagLib
перекомпилировать Dart-код и Flutter не требуется.

После распаковки комплекта команду выполняют из его корня. Для сборки
использовались GCC C++ и binutils в Ubuntu 22.04 x86-64, с заголовками
и библиотекой libcurl из дистрибутива.

```sh
export CXX=g++
bash musAni/tool/build_linux_taglib.sh /путь/к/flutter_taglib \
  /путь/к/изменённой/taglib-2.3 /путь/к/utfcpp-4.0.9 out

bash musAni/tool/relink_linux_taglib.sh relink/flutter_taglib.o \
  out/libtaglib-static.a out/libflutter_taglib_native.so
```

Распакуйте отдельную копию бинарного архива, закройте приложение и замените
в этой копии `lib/libflutter_taglib_native.so` полученной библиотекой.
Для контрольной перелинковки без изменений используйте
`relink/libtaglib-static.a` вместо `out/libtaglib-static.a`.

У пользователя есть право изменять библиотеку для собственного использования
и применять обратную разработку для отладки этих изменений. Правила лицензии
musAni приведены в `COPYRIGHT` и `LICENSE`. Лицензии сторонних компонентов
приведены отдельно.
