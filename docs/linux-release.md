# Установка musAni v0.1.0-alpha.1 на Linux

Выпуск предназначен для Linux x86-64 с glibc. Понадобится сеанс Wayland или X11
с работающим OpenGL/EGL/GLES и звуковым выходом. GTK 3 открывает окно приложения и
диалоги выбора файлов. media_kit загружает системную `libmpv.so.2` или другую
поддерживаемую версию libmpv. SQLite и libcurl предоставляются системой.
Flutter SDK, Dart, отдельная программа FFmpeg и системная TagLib для запуска
не требуются.

### Системные пакеты

Arch Linux

```sh
sudo pacman -S --needed gtk3 mpv sqlite curl libglvnd mesa
```

Ubuntu 24.04 LTS

```sh
sudo apt install libgtk-3-0t64 libmpv2 libsqlite3-0 libcurl4t64 libgl1 libegl1 libgles2 libegl-mesa0 libgl1-mesa-dri
```

`libmpv2` в Ubuntu находится в Universe. Используйте установленные драйверы
видеокарты и аудиостек своего дистрибутива. Названия пакетов в других
дистрибутивах могут отличаться. Для диагностики используйте `ldd ./musani`
и `ldd ./lib/libflutter_taglib_native.so`. libmpv и SQLite загружаются
динамически и могут не отображаться в списке `ldd ./musani`.

### Распаковка и запуск

Сохраните архив и его файл `.sha256` в одной папке.

```sh
sha256sum -c musAni-v0.1.0-alpha.1-linux-x86_64.tar.gz.sha256
tar -xzf musAni-v0.1.0-alpha.1-linux-x86_64.tar.gz
cd musAni-v0.1.0-alpha.1-linux-x86_64
./musani
```

Храните `musani`, `lib/` и `data/` вместе. Архив можно распаковать в папку
пользователя и запускать без root. Понадобится файловая система с правом
выполнения программ. Для каталога и редактирования тегов приложению нужны
обычные права на выбранные файлы.

### Обновление и данные

1. Закройте musAni.
2. При необходимости резервного копирования сохраните целиком каталог
   `${XDG_DATA_HOME:-$HOME/.local/share}/org.musani.player/`.
3. Распакуйте новую версию в отдельную папку и запустите её под тем же
   пользователем с тем же `XDG_DATA_HOME`.

`library/library.sqlite`, папки обложек, резервные копии тегов и
`shared_preferences.json` живут в каталоге данных приложения. Поэтому смена
папки установки не меняет библиотеку, настройки, плейлисты и порядок записей.
Эта альфа использует схему SQLite v5. Текущая очередь существует только
в памяти. Для возврата на старую версию, которая не поддерживает новую схему,
используйте копию каталога, сделанную до обновления.

### Совместимость

Архив проверен на Arch Linux и с runtime-библиотеками Ubuntu 24.04 LTS
в изолированном окружении. Для собранных ELF требуется glibc
не ниже 2.34 и libstdc++ с `GLIBCXX_3.4.29`. Это требования к ABI, а
совместимость также зависит от GTK, libmpv, драйвера и аудиостека.
Нужна SQLite с функциями JSON, которые обычные пакеты Debian, Ubuntu и Arch
предоставляют по умолчанию. Старые дистрибутивы, musl (Alpine), ARM и запуск
без графического сеанса в эту альфу не входят.

Для сообщения об ошибке укажите дистрибутив, Wayland или X11, версию libmpv
и шаги воспроизведения. Уберите из логов имена пользователей, пути к своим
файлам и другие личные данные.
